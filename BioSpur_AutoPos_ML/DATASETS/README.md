# DATASETS

This folder separates raw, messy experiment artifacts from cleaned datasets.

- `raw_captures/`: initial drop zone for historical test folders, raw logs,
  sweep outputs, generated reports, CSVs, JSONs, and other analysis artifacts.
- `raw_layouts/`: source or normalized layout files that can be ingested by the
  layout database builder.
- `optitrack_validation/`: ground-truth OptiTrack dataset for calibration and
  validation. This is limited validation data, not the primary training set.
- `processed/`: canonical cleaned data generated by scripts.
- `features/`: feature tables generated from processed layouts.

Rule of thumb: never manually clean inside `raw_captures/`; copy or transform
into `processed/` instead.

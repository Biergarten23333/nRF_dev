# V4-io intermediate files

`anchor_layout.json` is the frozen one-shot production-initialization output
retained as intermediate evidence. It converged in the reflected, higher-cost
layer basin. The canonical qualified deployment layout is
`../V4IO_LAYOUT.json`: the same frozen objective and SW100 input, with the
lower-cost mirror selected by the documented multistart rule. Pair distances
differ by at most 6.61 mm; no Tag data was used in that selection.

# BioSpur Pure-IMU Stage 3-R1

`BIOSPUR_EDGE_DIFFERENTIAL_YAW_RATE_ARRESTER_V1_1` estimates slow spatial-Z
yaw-rate bias on the nine directed parent-child edges. Applied edge correction
is a continuous unwrapped state and is summed through the fixed tree. This is a
rate-bias arrester, not an absolute-heading or anatomical-joint estimator.

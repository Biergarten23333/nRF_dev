# Frame and transform contract

Right-handed SI. T_A_B maps B coordinates to A. Active Hamilton quaternion order is [w,x,y,z], normalized, with q/-q equivalence. Error side, tangent frame, covariance order and linearization point are explicit. W requires FrameRealizationId. Ten independent L0_i gauges are never aligned before mapping; every T_L0_L0i is UNDEFINED. Future shared L0 exists only after Phase 2 mapping/extrinsics and Phase 3 observability.

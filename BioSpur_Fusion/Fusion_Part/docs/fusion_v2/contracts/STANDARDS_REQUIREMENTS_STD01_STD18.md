# Standards requirements STD-01–STD-18

1. **STD-01:** No IEEE compliance before normative clause audit.
2. **STD-02:** one canonical semantic source.
3. **STD-03:** standards never dictate estimator state or scientific PASS.
4. **STD-04:** physical identity and anatomical binding remain separate.
5. **STD-05:** native/common time and uncertainty semantics are preserved.
6. **STD-06:** unique unit/frame/transform semantics.
7. **STD-07:** calibration lifecycle classes remain separate.
8. **STD-08:** calibration artifacts are immutable and content-addressed.
9. **STD-09:** validity, observability, uncertainty, quality, health and claim level remain separate.
10. **STD-10:** ten directly instrumented carrier segments; head/hands/feet inferred or unavailable.
11. **STD-11:** HumanModel distinguishes fixed lengths from uncertain joints and donning.
12. **STD-12:** HumanState is sensor-agnostic with separate BioSpur provenance.
13. **STD-13:** UWB is antenna phase centre to fixed anchor at individual time.
14. **STD-14:** projection is EXACT, LOSSY_WITH_MANIFEST or REFUSED_UNREPRESENTABLE.
15. **STD-15:** dataset artifacts encode D0-D4 and sealed state.
16. **STD-16:** 9480 artifacts can only become rejected evidence.
17. **STD-17:** spec/schema/profile/implementation versions and Git SHA remain separate.
18. **STD-18:** privacy/data rights are recorded; formal standardization is post-P6.

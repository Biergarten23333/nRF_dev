# Data access policy

Only Phase 0 Prompt A §A6 exact realpaths are readable. Every access is pre-enabled and logged as BYTE_IDENTITY_ONLY, METADATA_ONLY or SCIENTIFIC_SAMPLE_ACCESS. D3 golf/boxing value fields are rejected before decode. No discovery, adjacent-path substitution or unfiltered persistent decompression is allowed. D1 and D2 views are separate, repo-external and content-addressed.

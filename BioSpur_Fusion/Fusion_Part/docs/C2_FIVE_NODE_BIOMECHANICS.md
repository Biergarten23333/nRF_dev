# 五节点：骨盆、末端与全身生物力学约束

研究日期：2026-09-07。本文是文献与当前实现的对应分析，不是新算法通过报告。本次只检索文献、读取代码并记录验证设计，没有修改求解器或运行新一轮拟合。

## 用户提出的场景

站立、双臂弯在身前，手腕和脚踝位置基本保持，身体前后移动且骨盆也运动。这个例子要求同时解释末端、骨盆和中间关节的运动。末端变化小不能自动推出上臂、胸廓或骨盆不动；缺失的关节也不能任意改变来补偿传感器误差。

在模型使用的共同世界坐标中，令 r_i = p_Tag_i - p_PelvisTag，则 r_i 的二阶导数等于 a_Tag_i - a_PelvisTag。四肢末端近似静止而骨盆发生加速时，相对加速度仍然提供信息。骨盆旋转还会通过固定骨长、髋部位置和躯干运动影响四条链的几何关系。这里的 p 是模型状态；纯 IMU 并没有直接测出这些三维位置。

佩戴在腹部前方的 Tag 不在骨盆关节中心，必须保留其杆臂引起的旋转加速度。低角速度和接近重力的加速度只能支持静止假设，不能单独证明零速度。空中保持的手没有地面接触，不得直接锁为已知空间点。胸廓也可以相对骨盆运动，不能把所有躯干变化强制归到 Pelvis。

## 当前代码已经做了什么、实际缺少什么

1. `c2_five_calibration/solver.py:23` 已使用四肢减骨盆的相对加速度；`geometry.py:69` 对应同一组传感器相对位置。因此不能将当前问题描述成“完全没使用 Pelvis”。
2. FK 连接全部骨段，实测肢段长度进入观测方程；当前不是四条完全独立的 IK。已有相对位置二阶导数约束会连接躯干与四肢。
3. `anatomy.py:89` 用一个公共胸部旋转驱动脊柱/锁骨相关节点，减少了随意变形，但也没有表达肩胛/锁骨活动。该简化的误差尚未在本项目中单独测量。增加自由度时必须同步增加有依据的耦合，不能恢复任意关节漂移。
4. 当前显式 ROM 主要是肘/膝屈曲区间；没有姿态相关的肩—肘、髋—膝可行域，也没有独立的胸廓相对骨盆活动范围项。骨长保持、屈曲不反号仍不等于整体姿态合理。
5. 求解器没有显式地面接触/足部支撑、非穿透或身体自碰撞项。跟随网络的关节位置/速度项不是这些约束的替代品。
6. `geometry.py:60` 在骨盆原点下计算位置，未估计世界平移。当前二阶差分有意消除了初始位置/速度；加入足部非滑移约束时，需要明确公共平移/速度的所有权，不能在骨盆固定为零的坐标中直接锁住两脚。
7. 五个校准后的方向目前被精确保留。生物力学层应与方向校准的不确定性协调，避免由上臂、胸廓吸收有偏输入。公开网络提供相关先验，不能计为另外五路测量。

## 按工程收益排序的改进

首先保留成熟 C2 的时间轴、功能轴、骨长、FK、已修正的关节屈曲定义和匹配加速度算子。把姿态相关关节可行域作为独立、可审查的因子接入姿态能量，尤其检查胸廓—骨盆和肩—肘的组合；不在显示层修改输出。

其次，在可靠支持的站立窗口评估接触条件。接触成立时，脚、腿、骨盆构成有额外约束的运动链。脚踝 Tag 实际在小腿，不能把小腿静止等同于整个脚掌静止。12/13 提踵尤其需要允许足部绕前掌转动；走步、跳跃和挥拳时不能全程双脚锁死。真实接触信息缺失时要用带置信度的假设。

再次，利用已有 C2 动作之间的结构：03、14、15检查骨盆/躯干运动；04/05检查肩部活动；06/07检查屈伸与旋前旋后的区别；08—13、16、18/19检查腿部与支撑。动作标签只路由适用的软关系，不指定准确关节角。所有已录制 C2 动作继续参与；没有新数据要求，也不恢复12/7划分。

肩胛细化、全身动力学和自碰撞按独立收益逐步接入，避免一次更换整套框架。姿态相关范围可以排除不合理解，但不能将真实少见姿态压成训练集里的常见姿态。站立平衡与快速动态动作也不能共用“质心投影永远在双脚之间”的硬规则。

## 把用户例子变成验证，而非口头判断

先建立三组带已知真值的短运动学场景，按实际五节点佩戴位置正向生成陀螺仪和含重力加速度。骨长使用现有身体尺寸。真值只用于测试评价，不送给重建器。

| 场景 | 需要排除的错误 |
|---|---|
| 骨盆运动、末端位置近似保持 | 把骨盆带着四个末端一起移动；用不合理肩/肘姿态补偿 |
| 骨盆近似保持、胸廓相对运动 | 错误强制胸廓与骨盆同步；把真实躯干变化判成方向漂移 |
| 躯干近似保持，分别做肘屈伸和前臂旋转 | 将轴向旋转解释成肘屈曲；把手臂动作传到腿部 |

每组先确认真实轨迹满足采用的生物力学模型，并生成真实的 Tag 杆臂运动；不能任意指定五个点的位置和方向后宣称它们来自合法人体。加入接触的版本须保留无接触/接触切换反例。比较同一输入和同一求解预算下的当前模型与单项新增约束，分别报告关节误差、末端漂移、传感器残差和错误接触次数。若存在两组都满足五节点信息与合理约束的姿态，必须保留歧义，不能凭较小先验损失宣称恢复真值。

随后对已有五路 C2 做同类检查。单项机制通过后再组合；校准参数冻结后统一进行 H01/H02 复现。十节点只由下游评估程序读取，用来比较冻结结果，不提供缺失段参数、关节标签或候选选择依据。

本次研究没有证明五节点已达到十节点效果。它明确了比继续调整四个固定航向更完整的改进方向：用适当的关节结构、姿态相关活动范围和条件接触，使骨盆与四肢共同限制缺失关节。

## AutoPos V2 preparation (offline, tomorrow-ready)

Goal:
- Prepare a V2 bidirectional-matrix processing chain for tomorrow's live test.

V2 design intent:
- Do not assume bidirectional measurements are symmetric.
- For each pair `(i,j)`, compute directional stats:
  - `n`, `mean`, `pstdev`, `var_mean`, `ci95`

## Unified BLE Tag build + runtime mode switch hardening (2026-03-31)

Goal:
- Keep one BLE Tag firmware image and switch between `Calibration` and `Motion` at runtime over BLE command.
- Improve command reliability under busy BLE/UWB by using short mode commands and deferred runtime apply.

Code changes:
- `include/uwb_tdma.h`
  - added runtime mode enum: `UWB_TAG_POSITIONING_MODE_CALIBRATION = 2`.
- `apps/tag/src/uwb_tag_ble.c`
  - removed calibration-build hard blocks for settings/config (`CFG_IGNORED_CAL`, `TDMA_SET_IGNORED_CAL` path removed).
  - added mode commands:
    - `MODE?`
    - `MODE CAL|MOTION|FIXED`
    - short aliases: `MCAL`, `MMOT`
  - `MODE` command now:
    - reads current runtime params,
    - updates in-memory mode,
    - applies mode defaults (cal mode disables TDMA gating defaults),
    - stores settings,
    - queues live apply via `ss_twr_init_runtime_configure`.
  - OTA busy guard: returns `ERR:BUSY_OTA` when OTA is active.
- `apps/tag/src/tag_app.c`
  - runtime config restore from BLE settings is allowed regardless of calibration build flag.
  - calibration build now sets calibration **default** mode, but runtime switch remains allowed.
- `src/ss_twr_init.c`
  - introduced runtime calibration detection (`positioning_mode == CALIBRATION`).
  - CM publish and TS suppression now depend on runtime mode (not only compile-time macro).
  - reject-path anchor advance behavior in calibration now runtime-driven.
  - TDMA wait/cut-short checks bypassed in calibration runtime mode.

Build entrypoint:
- added `scripts/build_tag_ble_unified.sh` (single unified BLE tag build wrapper).

Compile verification:
- command:
  - `./scripts/build_tag_ble_motion.sh 0 10 build-tag-ble-unified-tag115-test`
- result:
  - build success
  - artifact: `build-tag-ble-unified-tag115-test/merged.hex`

Operational note for busy command windows:
- Prefer short commands `MCAL` / `MMOT` over long `CFG ...` when BLE traffic is dense.
- Commands are persisted + queued for runtime apply; apply occurs safely at sweep boundary.

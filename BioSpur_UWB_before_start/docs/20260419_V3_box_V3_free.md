# 2026-04-19 V3-box and V3-free

This note defines the new `V3-box` and `V3-free` solver variants built on top of the repo `V3_full` implementation.

## Positioning in the Version Tree

- `V1`: baseline least-squares from raw inter-anchor distances
- `V2`: bidirectional fusion + iterative refine
- `V3-lite`: pragmatic stronger solve over the legacy constrained pipeline
- `V3-box`: robust `V3_full` solve with approximate paired upper/lower columns
- `V3-free`: robust `V3_full` solve with only lower-band / upper-band separation
- `V4`: reserved for future RotArm-enhanced solve

## Shared Core (`V3_full`)

Both `V3-box` and `V3-free` reuse the same core solver:

- V3 bidirectional fusion (`scripts/fuse_bidirectional_matrix_v3.py`)
- SDP / MDS seed (`scripts/sdp_init_v3.py`)
- per-anchor additive bias estimation
- Tukey IRLS on inter-anchor residuals
- optional floating Tag / CM reference sessions

Common range model:

```text
d_meas_ij ~= ||p_i - p_j|| + b_i + b_j
```

where:

- `p_i` is the 3D anchor position
- `b_i` is the additive anchor bias

## V3-box

`V3-box` is for deployments where the system still preserves four approximate upper/lower paired columns:

- `(A,E)`
- `(B,F)`
- `(C,G)`
- `(D,H)`

It does **not** require a perfect cuboid.

Allowed:

- irregular lower shape
- irregular upper shape
- skewed footprint
- T-like footprint
- upper/lower XY offsets

Preserved structural priors:

1. `A/B/D` define the gauge plane
2. `C` should stay close to that lower plane
3. `E/F/G/H` should stay at a similar upper height level
4. paired upper/lower height differences should be similar
5. optional paired XY alignment may be enabled, but remains off by default

Conceptually:

```text
V3-box = paired-column two-layer solver
```

## V3-free

`V3-free` drops the fixed paired-column assumption.

It only keeps:

- a lower band: `A/B/C/D`
- an upper band: `E/F/G/H`

The lower band and upper band are not required to be planar in the strict sense.
Instead, they are treated as two height-clusters:

- intra-band height spread is moderate
- inter-band height separation is large

Typical use case:

- lower group spread: `50 to 100 mm`
- upper group spread: `50 to 100 mm`
- lower/upper mean height gap: `1500 to 2000 mm`

Preserved structural priors:

1. `C` should stay reasonably close to the lower gauge plane defined by `A/B/D`
2. `E/F/G/H` should remain a compact upper height-band
3. the mean upper-band height should stay well above the lower-band mean height
4. no fixed `(A,E)/(B,F)/(C,G)/(D,H)` pairing is enforced

Conceptually:

```text
V3-free = free two-height-band solver
```

## Solver Entry Points

### V3-box

```bash
python3 scripts/prepare_autopos_v3_box.py \
  --pairs-csv <pairs_all.csv> \
  --out-dir <out_dir>
```

Main output:

```text
<out_dir>/anchor_layout_v3_box.json
```

### V3-free

```bash
python3 scripts/prepare_autopos_v3_free.py \
  --pairs-csv <pairs_all.csv> \
  --out-dir <out_dir>
```

Main output:

```text
<out_dir>/anchor_layout_v3_free.json
```

## Internal Geometry Mode

The shared solver `scripts/solve_anchor_layout_v3_full.py` now supports:

```text
--geometry-mode box
--geometry-mode free
```

So `V3-box` and `V3-free` differ by geometry priors, not by maintaining two unrelated optimization codes.

## Practical Guidance

- Use `V3-box` when you still trust the approximate upper/lower pairing.
- Use `V3-free` when anchors may be rearranged and only the two-band height structure remains valid.
- Keep `V4` free for future RotArm integration rather than overloading `V3` geometry changes into it.

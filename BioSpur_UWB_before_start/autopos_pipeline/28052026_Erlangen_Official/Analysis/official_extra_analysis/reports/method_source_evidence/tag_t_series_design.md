# T-Series Tag Positioning Design

The T-series names are reserved for BioSpur tag positioning. This avoids
confusion with AutoPos V1/V2/V3/V4 anchor-layout solvers.

## T1: Robust WLS Multilateration

Purpose:

```text
behavior-compatible baseline for current official Python solver
```

Model:

```text
r_i = ||p - a_i|| + d_anchor_i + d_tag - range_i
min_p sum_i huber(r_i / sigma_i)^2
```

Properties:

- per-frame 3D multilateration
- Gauss-Newton iterations
- anchor sigma weighting
- Huber robust residual weighting
- `d_anchor_i` from AutoPos `layout.json`
- `d_tag` normally `0`
- previous frame is only an initial guess, not a motion model

## T2: Quality-Aware Robust WLS

Purpose:

```text
downweight anchors with weak or recently weak ranging quality
```

Adds:

- current quality weighting
- short quality EMA

It does not reject anchors. It only changes effective sigma.

## T3: Dynamic-Stable Robust WLS

Purpose:

```text
optimize trajectory consistency for RotoArm and future body-motion captures
```

Adds:

- persistent-residual EMA soft downweighting
- weak previous-position motion prior
- no single-frame hard anchor rejection

RotoArm is a closer proxy for future dynamic BioSpur motion capture than a
single static tag. T3 therefore keeps the anchor set stable from frame to
frame. It should not reduce range residuals by throwing away geometry unless a
separate future NLOS mode explicitly enables that behavior.

## T4: Adaptive Redundancy Policy

Purpose:

```text
combine T1 full-anchor responsiveness with T3 low-redundancy stability
```

Current policy:

```text
if valid anchors >= 8:
    solve with T1 robust WLS, no previous-position prior
else:
    solve with T3 dynamic-stable weighting and weak previous-position prior
```

Rationale:

- full-anchor frames have enough geometry that temporal memory can carry NLOS
  or dynamic bias unnecessarily
- low-redundancy frames need T3 stabilization because keep-k tests show large
  degradation near 4-6 anchors
- hard leave-one-out rejection was tested and rejected because it damaged Roto
  consistency even when residual RMS decreased

## T4_V6_IMU_GATE: Accelerometer-Gated T4

Purpose:

```text
weaken low-redundancy temporal prior during detected Tag motion
```

Policy:

```text
if valid anchors >= 8:
    same as T4 v5, solve with memory-free T1
elif valid IMU summary exists:
    same as T4 low-redundancy path, but scale prior weight by std(|a|)
else:
    same as T4 v5 low-redundancy path
```

The IMU input is a per-UWB-frame summary generated by the Tag firmware, not raw
100 Hz samples. See `version_chain.md` for the TRv4 and parser naming.

## Current Implementation Status

The current implementation provides:

- C core solver for T1-T4
- Python wrapper for layout/capture IO
- CLI trajectory export
- outdoor validation script
- parser and wrapper plumbing for future `T4_V6_IMU_GATE`

T1 has been validated against the current official Python solver on the
`outdoor_20260513` dataset. T4 is the current experimental dynamic candidate;
see `validation_outputs/T4_VARIANT_COMPARISON.md` for MC500 evidence.

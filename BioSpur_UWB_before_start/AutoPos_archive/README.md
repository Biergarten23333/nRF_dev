# AutoPos Archive

This directory contains old AutoPos convenience bundles that used to live at the repository root.

## Archived Bundles

- `autopos_V1/`: old V1 capture + solve wrapper and historical logs.
- `autopos_V2/`: old V2 capture + solve wrapper and historical logs.
- `autopos_V3/`: old V3-lite wrapper, comparison scripts, and historical logs.

These bundles are kept for reference only. Active AutoPos development should use the top-level `scripts/` and `docs/` directories.

## Active Entry Points

Use top-level scripts such as:

- `scripts/run_autopos_sweep_loop.py`
- `scripts/run_autopos_sweep_and_solve_v3_box.py`
- `scripts/prepare_autopos_v3_box.py`
- `scripts/prepare_autopos_v3_free.py`
- `scripts/prepare_autopos_v3_full.py`
- `scripts/solve_anchor_layout_v3_full.py`

See `../AUTOPOS_WORKSPACE.md` for the current workspace direction.

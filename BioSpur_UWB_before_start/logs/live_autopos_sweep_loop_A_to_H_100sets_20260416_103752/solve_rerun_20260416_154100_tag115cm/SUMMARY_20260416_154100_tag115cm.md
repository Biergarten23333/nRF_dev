## Key Conclusions

- On this dataset, `V3-full + Tag115 CM` is clearly best by holdout RMS.
- `V3-full no115` does not improve over V1/V2 on holdout; it is close to V3-lite and significantly worse than `V3-full + Tag115 CM`.
- `V1` and `V2` are effectively identical in this run (same holdout stats).
- The gain of V3-full in this run comes from actually using Tag115 CM in solve, not from the V3-full optimizer alone.

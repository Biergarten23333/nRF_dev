# Scripts

Planned command-line entry points for the standalone offline tag positioning
solver.

Current scripts:

```text
export_trajectory.py
  layout.json + capture directory -> trajectory JSON/CSV

export_trajectory_t.py
  layout.json + tr_all.csv/capture directory -> trajectory JSON

validate_outdoor_dataset.py
  run T1-T3 on outdoor_20260513 and compare T1 against the current official
  reference implementation
```

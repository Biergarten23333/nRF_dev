### 时间结构(LCCF4←BSCCF4,强回波 tap)

- 主导尾部 bump 在 tap **[6, 11, 21] = [1802, 3303, 6306] mm** 路径超程(对上已知 0.9 / 1.6 m 反射体)。

### 判决

- **COHERENT SAR:可行**(远低于 40° 阈值)。

### ⚠️ 诚实 caveat

2. **帧率 ~1.3 Hz:** 对 0.3 Hz 呼吸只是勉强过 Nyquist(0.6 Hz 下限);双站回波 σ_φ 10–30°,呼吸检测在双站上偏边缘。

## 关键新结论(影响 Q4 上限)

**Coherent SAR 的瓶颈是运动学知识,不是信道相位相干性。** 信道相位噪声 2–4°(热噪声极限,整夜零漂,相干 >6h);而转速抖动贡献 ~5–13°/圈的相位代价、位置噪声 110 mm 是主导误差项。**信道比我们对天线在哪儿的了解更稳** → 往上限走要投的是 autofocus / 轨迹估计(用双标弦估每圈周期做补偿),不是 RF。

## Item 1 — NULL CHECK(裁决所有 σ_φ 的有效性)✅

天真判据「pre-FP 噪声 tap 应 → 均匀 ~104°」在本装置**不成立**,而搞清为什么正是结论:静态高 SNR 装置的相干信道响应(脉冲 + accumulator ringing + 近场多径)**很宽**,所以 pre-FP tap 不是纯噪声。判别在于它们的相干度**随链路 SNR 变化**:

| 链路 | FAR taps(28–43前) linσ | NEAR taps(6–16前) linσ | ECHO σ |
|---|---|---|---|
| LCCF4←BS9336(弱) | 44° | 66°(趋近均匀) | 9.5° |
| LCCF4←BSCCF4(强单站) | 14° | 9°(相位稳) | 3.9° |

自参考 **bug 会是与链路无关的均匀相干**;这里强烈依赖 SNR → 是**物理泄漏**,不是 bug。

**决定性对照 — phase-shuffle**(用别帧的 FP 参考本帧):
- 正常同帧参考 → echo σ = **3.9°**
- 打乱参考 → echo σ = **157.7°**(linσ=102° = 均匀极限)

打乱把相干性摧毁 → 低 σ_φ 是**真实静态信道相位稳定性**,非数值假象。**管线有效,σ_φ 全部成立。**

## Item 2 — FP-ref 噪声核算 ✅

SNR 约定:**幅度比 20·log10(mean|CIR| / 噪声地板)**,地板用 **FAR(干净)pre-FP tap 的跨帧 mean|CIR| 中位**。
在被指「2.3°@30dB」的 tap(LCCF4←BSCCF4,+3):观测 **2.34°**。分解:
- 原始 1.8× gap 对 `1/√(2·SNR)` = (i) 约定差:audit 用 mean|noise| 当地板,热噪声定律要 rms(mean|Rayleigh|=√(π/2)·σ=1.25×);(ii) **FP 参考是前沿样本(~27 dB,非无穷)**,自身相位噪声 σ_FP≈1.5° 按平方相加。
- σ_total≈1.7°,残 **1.39×**(近 FP 脉冲裙重叠 / 幅度衰落)。**无大额外噪声**(时钟/振动会是 5–10×)。有效相位地板 **~2.3°** —— 仍是 coherent 级。

## Item 3 — 每链路帧率(裁决 0.27 vs 1.3 Hz 矛盾)

| | 每(listener,tag)链路 | 每 listener 聚合 |
|---|---|---|
| soak(3 tags) | **~0.48 Hz** | 1.43 Hz |
| roto(5 tags) | **~0.46 Hz** | 1.74 Hz |

## 判决:coherent SAR **成像**受"轨迹位置地板"限制,不是信道相干性

**一句话:信道是相干的(回波相干增益确实 >> null,与 σ_φ 结论一致),但轨迹位置知识 ~100 mm ≈ 2.2λ 的随机地板,使回波无法聚焦成干净、定位一致的像;而这 100mm 里只有 12–22% 是可被 autofocus 建模的系统 runout,其余是随机多点定位噪声,autofocus 救不回来。** → 唯一能改变结论的实验是**角反射器**(强已知目标,才能做逐帧自校准打穿位置地板)。

## Stage 0 — 正确的联合刚性圆拟合(修掉旧 Δφ 假象)

- center=[3219,2116,983],normal=[-0.085,-0.729,0.679],R=452/543 mm(对上 kinematics 435/534)。
- **Δφ = −172.7° ± 31.2°**(旧"联合"拟合 ±157° 是 round(t,1) 采样错配的假象;确认两标 ~180° 刚性对装)。σ 仍非 <5°,因每采样角噪声 = 位置噪声/R。
- **弦角 θ 不如单标 θ**(per-rev σ:弦 7.3% vs 单标 4.2–4.9%)→ 用户设想的"双标弦绕过 1/R"在本装置**不成立**:TDMA 两标非同时采样,弦差反而叠加独立噪声。相位模型 = 单标平滑角。
- 拟合模型位置残差 ~155 mm(相对**含噪的**多点定位;是比较噪声,不全是模型误差)。
- **runout 一次谐波:radial 45–58mm(只解释 12–22% 方差,残 ~100mm)、axial 21–46mm(解释 33–35%,残 73–84mm)** → 系统 runout 很小,**误差主体是 ~100mm 随机地板**。这是全案的关键预测量。

## Stage 2 — 正控:近场静结构聚焦(**方法学关键**)

匹配滤波 S(x)=Σ z(τ_pred)·exp(−j2π·excess/λ),近场 6 链路。

- ⚠️ **陷阱**:朴素增益 |S|²/Σ|z|² 给出 ~2000×(70–87% of N)——**是假象**。FP-referenced 近 FP 区被一个近乎**常数**的直达路径裙主导(正是 σ_φ 审计测到的极端相位稳定!),`|Σz·e^{−jφ}|²` 大且**对 θ 置换不变**,能扛过 scramble。
- ✅ **正确度量 = 用户原始的 |S|²/E[|S_scrambled|²]**(array-factor 在分子分母都在,相除抵消)。用它:**中位增益 ≈ 1.0(null 校准正确)**;峰值 44–101×(> 纯 null 上限 ~ln N≈9,说明**有真实相干回波能量**),**但峰值位置各链路不一致、定位比只有 2–5×** → 无干净定位聚焦。严格判据(≥10× null 且 ≥3× 定位、≥2 链路)只 1/6 过。

## Stage 3 — Autofocus(runout+scale),对**重新优化的** null 公平比

- runout(从轨迹测得,非拟合到 CIR)+ scale s∈[0.95,1.08] 扫描;scramble null 用**同参数**重算(公平)。
- raw 峰值 [109,196,75,115]×;runout+scale 峰值 [113,120,100,280]×。**runout/raw 改善比 = [1.04, 0.61, 1.33, 2.43],中位 1.19** → **autofocus 不系统性改善**(一好一坏)。峰值仍各链路乱跳、s 不收敛到干净值(无 ~4.4% scale 独立佐证)。
- 注:75–280× 的峰是 ~8k voxel × 6 scale 的**多重比较尾**,raw 本身就"过 10×";真问题是 autofocus 是否**系统性锐化**——答案否。
